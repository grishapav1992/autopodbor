# Рекламный текст (Promotional Text) для App Store

Поле «Рекламный текст» в App Store Connect: до **170 символов**, показывается
над описанием (iOS 11+ / macOS 10.13+), можно менять в любой момент **без
новой сборки и без ревью бинарника**.

## Вариант B — для специалиста (рекомендуемый, 166 симв.)

> Рабочий инструмент автоподборщика: отчёты осмотра с фото и замерами ЛКП, проверка залогов и такси по VIN, скан СТС с автозаполнением, ИИ-итог. Всё в одном приложении.

Основной пользователь приложения — специалист по осмотру / компания
(конструктор отчётов, заявки, штат сотрудников), поэтому текст целит в него.

## Вариант A — для покупателя авто (155 симв.)

> Проверьте авто до покупки: осмотр по чек-листу, фото и видео, замеры ЛКП, юридическая проверка по VIN и госномеру, ИИ-сводка. Отчёт готов прямо на осмотре.

Шире охват по запросам «проверка авто перед покупкой» — если позиционируем
стор-страницу на заказчиков, а не исполнителей.

## Вариант C — короткий продающий (155 симв.)

> Полный отчёт об осмотре авто за один выезд: чек-листы, фото и видео, юрпроверки по VIN, скан СТС и ИИ-сводка. AutoBase — быстрее, чем бумага и мессенджеры.

Акцент на скорость и замену «бумаги и мессенджеров» — контраст с привычным
процессом.
