# Коды ошибок для техподдержки

Внутренние коды, которые приложение показывает пользователю при ошибках
(баннер ошибки выгрузки отчёта, строка «Код: …» в снекбарах) и вкладывает в
копируемый текст «для поддержки». Пользователь может нажать «Скопировать» и
прислать весь блок — в нём код, сообщение, номер отчёта (`REP-…`), этап
выгрузки, время и техническая ошибка.

Источник констант: `lib/ui/mobile/screens/dealer/spark_joy/spark_joy_error_snackbar.dart`
(`SparkJoyErrorCode`). Коды стабильны: значения не переиспользовать и не
менять; новые — добавлять и сюда, и в класс.

## Формат копируемого блока (выгрузка отчёта)

```
Ошибка выгрузки отчёта
Код: NET-02
Сообщение: Сервер не ответил вовремя. Проверьте подключение и повторите.
Отчёт: REP-A743739
Этап: Готовим отчёт на сервере (это может занять 1–3 минуты)…
Время: 2026-07-06T19:29:41.000
Техническая ошибка: ClientException with SocketException: HTTP connection timed out after 0:00:10.000000, host: app.carreports.ru, port: 443, uri=https://app.carreports.ru
```

## Сеть (проблема на стороне пользователя или до сервера)

| Код | Что случилось | Что сказать пользователю | На что смотреть разработчику |
| --- | --- | --- | --- |
| NET-01 | Нет доступа к сети: DNS не резолвится, сеть недостижима | Проверить Wi-Fi/LTE, авиарежим, повторить | Обычно не наша проблема; массовость → проверить DNS `app.carreports.ru` |
| NET-02 | Таймаут соединения или ответа | Проверить качество связи, повторить — выгрузка продолжится с места остановки | Если стабильно у многих — нагрузка/доступность бэка, nginx |
| NET-03 | Соединение оборвалось на середине (reset/closed/broken pipe) | Повторить попытку | Смена сети (Wi-Fi→LTE), прокси/VPN; массовость → nginx/бэк рвёт соединения |
| NET-04 | Сервер отверг подключение (connection refused) | Попробовать позже | Сервис лежит или порт закрыт — проверить бэк немедленно |
| NET-05 | Не установилось TLS-соединение (handshake/сертификат) | Обновить приложение до последней версии, попробовать другую сеть | Ротация TLS-сертификата при устаревшем cert-pin в билде (см. SECURITY.md и инцидент 2026-07-02); MITM-прокси/корп. сеть |
| NET-06 | Прочий сетевой сбой без деталей | Проверить интернет, повторить | Смотреть техническую ошибку в блоке |

## Сервер

| Код | Что случилось | Что сказать пользователю | На что смотреть разработчику |
| --- | --- | --- | --- |
| SRV-01 | HTTP 5xx / bad gateway | Повторить через несколько минут | Логи бэка/nginx за время из блока |
| SRV-02 | HTTP 429 / rate limit | Подождать минуту и повторить | nginx limit_req (~20 r/s per-IP); частые жалобы → пересмотреть лимит |
| SRV-03 | Некорректный/пустой ответ, действие не подтверждено | Повторить позже | Ответ не JSON (например, HTML от nginx), контракт метода |
| SRV-04 | Бэк отклонил операцию бизнес-кодом | Зависит от сообщения (оно уже человеческое) | Строка «Код сервера: …» (snake_case) и «Метод: …» в блоке |

## Авторизация

| Код | Что случилось | Что сказать пользователю | На что смотреть разработчику |
| --- | --- | --- | --- |
| AUTH-01 | Сессия истекла / HTTP 401 | Выйти и войти заново | RefreshToken-цепочка, время жизни токена (~12ч) |
| AUTH-02 | Недостаточно прав / HTTP 403 | Действие недоступно роли; обратиться к владельцу компании | RBAC: метод из строки «Метод: …», роль пользователя |

## Файлы отчёта (выгрузка в S3)

| Код | Что случилось | Что сказать пользователю | На что смотреть разработчику |
| --- | --- | --- | --- |
| FILE-01 | Локальный файл не прочитался с устройства | Переснять/добавить файл заново | Источник медиа устарел (чистка кэша, iCloud-выгрузка) |

| FILE-05 | Хранилище не приняло файл (presigned URL / ETag / multipart) | Повторить позже | ObjectStorage.* методы, S3, CORS на web |
