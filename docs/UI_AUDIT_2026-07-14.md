# UI/UX-аудит AutoBase — 2026-07-14

Аудит интерфейса «глазами фронтендера + дизайнера»: шрифты, консистентность, неровности.
Методика: статический анализ кода (grep + чтение) + живой проход по web-сборке в Chrome
(debug, `flutter run -d web-server`, viewport 375×812, вход по dev-токенам, роль company).

**Дисклеймер по web-прогону:** Flutter web рендерит текст через canvaskit; до фикса №1
шрифт тянулся с fonts.gstatic.com. Начертания на web = Roboto, а не SF Pro как на iOS —
выводы по рисунку шрифта «ориентировочные», по раскладке/отступам/поведению — достоверные.
Артефакт среды: скриншоты пейна рисовались в ~81% масштаба (эмуляция dpr), на реальное
приложение не влияет (`flutter-view` проверен — полноразмерный 375×812).

## 0. Резюме

1. **P1 (web/PWA, ИСПРАВЛЕНО):** в приложении не было ни одного забандленного шрифта —
   движок Flutter web качает Roboto/Noto с `fonts.gstatic.com`, который из РФ-сетей
   не отвечает → **PWA рендерилась вообще без текста** (проверено живьём: пустые кнопки,
   пустые заголовки). Забандлен Roboto (400/500/700) в `assets/fonts/` + `pubspec.yaml`.
2. **Типографика раздвоена:** spark_joy живёт на токенах `SparkTextSize` (477 использований),
   легаси-экраны (auth, nav_bar, auto_request, common/widgets) хардкодят 10–24px вперемешку,
   включая дробные 12.0/12.5. `Theme.of(context).textTheme` не используется **ни разу**.
3. **Токен `AppFonts.URBANIST` — обманка:** возвращает системные 'SF Pro Text'/'Roboto'.
   Urbanist в проекте нет. На iOS имя 'SF Pro Text' скорее всего не резолвится → фактический
   шрифт берётся из fallback ('Helvetica'). Стоит проверить на устройстве и назвать честно.
4. Живой проход дал десяток конкретных находок (ниже): от «висящего» текста в детали заявки
   до преждевременной красной валидации в редакторе отчёта.
5. Быстрые победы применены (раздел 3), analyze чистый. Крупные рефакторинги — раздел 4.

## 2. Находки статического анализа

### Типографика
- **0 обращений** к `Theme.of(context).textTheme`; `textTheme` в `light_theme.dart` не
  кастомизирован — вся типографика задаётся вручную на 116 `TextStyle(` + 707 `MyText(`.
- Вне spark_joy размеры хаотичны: 10×4, 11×3, **12×21**, 12.0×2, ~~12.5×1~~, 13×1, 14×6,
  15×1, 16×1, 18×4… (11/12/12.5/13/14/15 для «мелкого текста» без шкалы).
- `letterSpacing` подобран на глаз: -0.4 / -0.2 / 0.5 / 0.6 / 8 (6 вхождений).
- Межстрочный (`height`) системно не нормирован.
- Токены `SparkTextSize` (chip 10 … hero 26) — только размеры, без готовых стилей
  (weight/height); используются почти исключительно в spark_joy.

### Цвета
- Дубли в палитре: `kPrimaryColor == kLightGreyColor` (0xffF6F7F8),
  `kGreyColor == kHintColor` (0xff6B7280), ~~`kRedColor == kRedColor2`~~ (устранено).
- Три разных «зелёных успеха»: `kGreenColor` 0xff2E7D32, `kChipCompletedFg` 0xFF1C7C3D,
  инлайн 0xFF6EE7B7 (vin_scanner).
- Сырые `Colors.black`×18, `Color(0x...)`-литералы ×73 (~30 одноразовых пастельных hex в spark_joy).

### Компоненты и метрики
- Кнопки: `MyButton`×31 сосуществует с `OutlinedButton`×84, `FilledButton`×35,
  `TextButton`×55 — единого контракта нет.
- AppBar: `simpleAppBar()`×23 vs сырой `AppBar(`×59 vs кастомные Header в spark_joy.
- Радиусы вне spark_joy: 12×45, 10×33, 8×31 — три конкурирующих «радиуса карточки».
- Отступы: `horizontal: 15`×12 против стандарта `AppSizes.DEFAULT = 20`.
- Токены spacing/radius вне spark_joy: 26 и 18 использований против 1234/261 внутри.
- Тёмной темы нет (`themeMode: ThemeMode.light` захардкожен в 2 точках входа), Material 2.

## 4. Крупные рефакторинги — только описание (по убыванию ценности)

1. **Единая шкала типографики.** Создать `AppTextStyles` (готовые стили: размер+вес+height)
   на базе `SparkTextSize`, прописать в `TextTheme` темы, мигрировать легаси-экраны
   (auth → nav_bar → auto_request → common/widgets). Заодно решить судьбу имени `URBANIST`
   (переименовать в `SYSTEM`) и проверить на iOS-устройстве, что реально резолвится
   ('SF Pro Text' vs Helvetica).
2. **Палитра статусов.** Один словарь статус→(bg, fg) для чипов заявок/отчётов/шагов
   (расширить существующие `kChip*`), убрать серые «Создана/В работе».
3. **Единый контракт кнопок.** Довести `MyButton` до вариантов primary/secondary/outlined/
   destructive + единый disabled-стиль; запретить сырые Outlined/Filled в новых экранах.
4. **Нормализация отступов/радиусов легаси:** 15→20 (13 мест), радиусы 8/10/12 → `SparkRadius`.
5. **Дедуп палитры:** `kHintColor`→`kGreyColor`, `kLightGreyColor`→`kPrimaryColor` (или
   наоборот, по смыслу), три «зелёных» → один + оттенки; вынести 30 одноразовых hex spark_joy.
6. **Плейсхолдеры изображений** (шиммер для аватарок/иллюстраций) + скелетоны списков
   вместо «История пуста»/пустых состояний до загрузки.
7. **Тёмная тема** — только после пунктов 1 и 5 (иначе рефакторить придётся дважды).
