# Spark Joy UI Migration Baseline

Дата фиксации: 2026-04-06  
Ветка: `codex/work-20260406-next`

## Цель

Зафиксировать текущее поведение и UX-состояние перед полной миграцией визуала под единый Flutter UI-шаблон, без изменения бизнес-логики.

## Ключевые флоу для контроля

1. Создание отчёта (название, назначение сотрудника, переход в мастер).
2. Раздел `Автомобиль`.
3. Раздел `Параметры`.
4. Раздел `Сверка документов`.
5. Раздел `Юридическая проверка`.
6. Раздел `Осмотр` (группы, файлы, заметка элемента, теги).
7. Раздел `Тест-драйв`.
8. Раздел `Итог`.
9. Компания: `Отчёты / Сотрудники / Профиль`.

## Статус миграции по экранным блокам

- `Отчёты`: частично мигрирован (единая шапка, primary action, поиск).
- `Новый отчёт`: частично мигрирован (единая шапка и поля формы).
- `Профиль`: частично мигрирован (единая шапка и поля/инпуты).
- `Сотрудники`: частично мигрирован (единая шапка, поиск, заголовки секций).
- `Детали сотрудника`: частично мигрирован (шапка, секция, карточки).
- `Legacy assignment`-экраны: удалены из рабочей ветки как неиспользуемые в текущем UX-потоке.
- `Создание отчёта` (мастер): частично мигрирован (общий декоратор полей), далее миграция идет по шагам.

## Гейты регрессии после каждого раздела

1. `flutter analyze` без ошибок.
2. Smoke-проход по измененному разделу:
   - открыть раздел;
   - заполнить обязательные поля;
   - выполнить сохранение/переход;
   - вернуться назад и убедиться в сохранении состояния.
3. Ручная проверка на iPhone (по команде пользователя) для измененного раздела:
   - клавиатура/фокус;
   - медиа/аудио (если затронуто);
   - стабильность навигации.

## Прогресс текущей итерации

- `Автомобиль`: обновлены секционные заголовки и композиция блока города осмотра.
- `Параметры`: добавлены единые секционные заголовки.
- `Сверка документов`: добавлен единый секционный заголовок.
- `Юридическая проверка`: добавлены секционные заголовки для статуса, файлов и комментария.
- `Осмотр`: добавлены секционные заголовки для пробега, обязательных и дополнительных групп.
- `Тест-драйв`: добавлены секционные заголовки для режима, проверки узлов и комментария.
- `Итог`: добавлен структурный заголовок для блока разделов отчёта.
- Базовые карточки централизованы через `SparkCard` (включая мастер отчета и комментарии).
- Теги/плашки статусов в `Осмотр` переведены на общие UI-компоненты (`SparkSelectableChip`/`SparkChip`).
- Шапка редактора группы в `Осмотр` переведена на `SparkCard`, с защитой от переполнения длинных заголовков.
- Верхняя шапка шага в мастере отчёта вынесена в общий компонент `SparkStepHeader`.
- Нижняя панель действий шага вынесена в общий компонент `SparkStepActionBar`.
- Карточки разделов и прогресс в overview мастера вынесены в `SparkSectionNavCard` и `SparkProgressSummaryCard`.
- Плашки статусов и attention в разделе `Итог` переведены на общий `SparkChip`.
- Удалены неиспользуемые legacy-экраны Spark Joy, не подключенные в навигации.

## Область текущего этапа

Текущий этап: `Итог` (UI и композиция, без изменения логики).

Ограничения:
- не менять валидации и обязательность;
- не менять сохранение черновиков;
- не менять VIN-сканирование логику;
- не менять переходы между шагами.
