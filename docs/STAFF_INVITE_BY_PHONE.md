# Приглашение специалиста по телефону в штат компании

В разделе `Сотрудники` у компании есть кнопка `Пригласить по телефону`.
Функция нужна, чтобы пригласить в штат уже зарегистрированного специалиста.

Пользователь нажимает `Пригласить по телефону`, после чего открывается
модальное окно с полем ввода телефона. Фронт нормализует введённый номер:
удаляет все символы, кроме цифр, проверяет что введено минимум 10 цифр, берёт
последние 10 цифр и приводит номер к формату `+7XXXXXXXXXX`. Если номер
неполный, показывается ошибка:

```text
Введите полный номер телефона
```

После нормализации фронт ищет специалиста через метод:

```json
{
  "method": "Storage.GetSpecialists",
  "params": {
    "search": "+7XXXXXXXXXX",
    "limit": 20
  }
}
```

После ответа фронт дополнительно фильтрует найденных специалистов по последним
10 цифрам поля `specialist.phone`, чтобы не зависеть от формата телефона на
бэке (`+7`, `7`, `8`, пробелы, скобки и т.д.).

Если специалист с таким телефоном не найден, показывается ошибка:

```text
Специалист с этим номером не найден. Сейчас можно пригласить только зарегистрированного специалиста.
```

Если специалист найден, фронт проверяет, не состоит ли он уже в штате текущей
компании. Для этого используется список сотрудников компании, загруженный через:

```json
{
  "method": "Storage.GetCompanySpecialists",
  "params": {
    "page": 1,
    "limit": 100
  }
}
```

Проверка выполняется сравнением `specialist.id` найденного специалиста с id
сотрудников из штата. Если специалист уже есть в штате, показывается ошибка:

```text
{Имя специалиста} уже в штате компании
```

Если специалист найден и его ещё нет в штате, фронт отправляет ему
уведомление-приглашение через метод:

```json
{
  "method": "Notification.SendNotification",
  "params": {
    "type": "invitation",
    "recipientId": 123,
    "title": "Приглашение в штат",
    "body": "Компания приглашает вас присоединиться к штату специалистов в Autopodbor.",
    "payload": {
      "source": "spark_joy_company_staff",
      "phone": "+7XXXXXXXXXX"
    }
  }
}
```

Где `recipientId` — это `id` найденного специалиста из
`Storage.GetSpecialists`.

После успешной отправки уведомления компания видит сообщение:

```text
Приглашение отправлено: {Имя специалиста}
```

После этого фронт обновляет список сотрудников компании через
`Storage.GetCompanySpecialists`.

Со стороны специалиста приходит уведомление с типом `invitation`. В уведомлении
есть действия `Принять` и `Отклонить`. Если специалист нажимает `Принять`,
фронт вызывает:

```json
{
  "method": "Notification.ActionNotification",
  "params": {
    "notificationId": "notification-id",
    "action": "accept"
  }
}
```

После принятия уведомления бэк привязывает специалиста к компании. После этого
специалист должен появиться в списке сотрудников компании при следующем вызове:

```json
{
  "method": "Storage.GetCompanySpecialists",
  "params": {
    "page": 1,
    "limit": 100
  }
}
```

Важно: кнопка `Пригласить по телефону` не добавляет специалиста в штат сразу.
Она только отправляет уведомление-приглашение. Фактическая привязка специалиста
к компании происходит на бэке только после того, как специалист принял
уведомление `invitation`.

Также важно: этот flow не использует `Storage.CreateStaffInviteLink`. Ссылки
приглашения здесь нет. Приглашение работает только для уже зарегистрированных
специалистов, найденных через `Storage.GetSpecialists`.
